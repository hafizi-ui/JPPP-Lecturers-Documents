# JPPP Lecturer's Documents

Laman: https://hafizi-ui.github.io/JPPP-Lecturers-Documents/

Portal untuk pensyarah menghantar dokumen (kertas kerja, minit curai, CIR, penilaian) yang memerlukan tandatangan Ketua Jabatan, dan untuk KJ menyemak dan menandatangani dokumen itu secara elektronik, termasuk kod QR untuk semakan ketulenan.

- Frontend: HTML + CSS + JavaScript vanilla (GitHub Pages)
- Backend: Google Apps Script + Google Sheets + Google Drive (`Code.gs`, `appsscript.json` – tampal dalam Apps Script)
- Biarkan `API_URL` kosong dalam `config.js` untuk **Mod Demo**

Panduan pemasangan: lihat `PANDUAN_GITHUB.md`.
